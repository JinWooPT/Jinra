# Jinra interface screenshots

These are unedited captures of the running Windows application, saved in the JPEG
format provided by the capture tool. They show the real library and automatic
DualSense detection, rather than interface mockups.

Library entries illustrate game detection. Only Donkey Kong Bananza has been
validated for this release; the presence of another game cover does not establish
compatibility. No game files, keys, firmware or profiles are included here.
